# Свечной RECOVERY (PAPER)

Применяется только в `PaperSession`. MT5 является источником данных: виртуальные
позиции, ордера и расчёт прибыли остаются в SQLite. EA не нужен и не добавлен.

## Вход и объём

Начальная настройка нового состояния: 0.02 лота. Первоначальный вход сохраняет
собственные TP/SL настройки. После закрытия с остатком долга следующая лестница
ожидает новую закрытую свечу. Зелёная свеча задаёт BUY STOP, красная SELL STOP,
на настроенном расстоянии от close. Пока ордер не исполнен, смена цвета отменяет
и заменяет ожидающую лестницу. Doji не создаёт входа. STOP не заменяется MARKET.

После полного исходного SL всей корзины объём следующей увеличивается на 0.01.
Любой фактически перенесённый SL считается поддержкой; при его исполнении объём
не повышается. Частичный TP плюс SL остатка также сохраняет объём. Один исход
корзины учитывается один раз, включая перезапуск. После полного SL объёма 0.10
автоматические входы приостановлены до выбора объёма/TP-профиля и возобновления.

Каждая RECOVERY-ступень имеет объём 0.01. Профили редактируемые:

| Объём | TP расстояния в единицах цены |
|---|---|
| .02 | .30, .70 |
| .03 | .30, .70, 1.00 |
| .04 | .50, 1.00, 1.50, 2.00 |
| .05 | .70, 1.30, 1.90, 2.40, 2.70 |
| .06 | .70, 1.30, 2.00, 2.80, 3.30, 3.90 |
| .07 | .70, 1.30, 2.30, 3.00, 3.50, 4.30, 4.90 |
| .08 | .70, 1.30, 2.30, 3.30, 4.00, 4.70, 5.10, 5.60 |
| .09 | .70, 1.30, 2.30, 3.30, 4.00, 4.70, 5.50, 6.30, 6.90 |
| .10 | .70, 1.30, 2.30, 3.30, 4.00, 4.70, 5.50, 6.50, 7.50, 8.20 |

Последняя доступная открытая ступень корректируется по остатку RECOVERY с вычетом
ожидаемого дохода других ещё открытых ступеней и учётом модельных расходов.
Ранее реализованная прибыль повторно не вычитается. Последний TP может оказаться
ближе предыдущих. Если расчёт требует нулевой/отрицательной прибыли последней
ступени, текущий положительный TP сохраняется: убытковый TP или немедленное
закрытие автоматически не создаются. Остаток долга не списывается. Подтверждённый ручной TP на графике имеет приоритет: автоматический расчёт не перезаписывает его, пока текущий TP совпадает с ручной отметкой.

## SL и кнопки

BUY: при Bid >= вход+.25 SL переносится на вход-.25; при Bid >= вход+.40 на вход.
SELL зеркально по Ask: вход-.25 -> SL вход+.25; вход-.40 -> SL вход.
Три расстояния доступны в настройках. Это единицы цены, не `_Point`.
Более выгодный ручной SL не ухудшается. При недопустимом переносе прежний SL
остаётся на месте. Неисполненные фиксированные триггеры на SL не следуют за
свечами или последующим переносом исходного SL.

Ручная панель MARKET/STOP удалена. Сохранены отмена триггеров, контроль SL,
обратная лестница, триггеры на SL, SL на вход, закрытие всех позиций, прерывание
PAPER-цикла, ручное перемещение линий с подтверждением, сброс RECOVERY без позиций.
Виртуальные ручные действия с ценой используют последнюю доступную корректную
котировку, не запускают повторное проигрывание старых свечей.

## Совместимость и проверки

Старые профили архивируются в состоянии; открытые позиции, ордера, активные
снимки профилей, история и долг не удаляются. Старые контроллеры сохранены для
совместимости и регрессионных проверок, но новый PAPER runtime выбирает свечной.
Новая установка не импортирует прошлые сделки реального MT5.

Модель времени: [PAPER_RAW_TIME_RU.md](PAPER_RAW_TIME_RU.md).
Проверки выполняются offline на виртуальном исполнении; это не проверка
рыночного исполнения или доходности. Прямые записи MT5 запрещены архитектурой.

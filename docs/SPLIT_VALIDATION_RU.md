## Результаты локальных проверок

Среда: Linux, Python 3.13.5, Node.js 24.22.1.

- 441 Python-тест пройден; runner запрещает реальные сетевые подключения, зафиксировано 0 попыток.
- Три Node-набора пройдены: обработчики RECOVERY V3, высота графика, уведомления/статусы.
- Статические проверки HTML/JS структуры, ID и доступности команд пройдены.
- `compileall`, синтаксис JavaScript, импорт всех production-модулей `tradfi` и офлайн V3 demo пройдены без исходного торгового репозитория.
- Отдельный реальный HTTP smoke на loopback с синтетическими котировками: HTML/JS/CSS, авторизация, PAPER state/action, отказ `/api/action` с 404, инвалидирование сессии после выхода.

## Что проверяют тесты разделения

- Нет LIVE entrypoints, торгового MT5 adapter, EA и вызовов `order_send`/`order_check` в production-коде.
- CLI отклоняет `mt5`, `gateway` и `--execute`; `enable_trading: true` отклоняется до инициализации MT5.
- MarketReader не хранит native API и получает только read-only capabilities; заглушки запрещают торговые методы и login.
- PAPER команды через транспорт не изменяют отдельную синтетическую «LIVE» базу.
- Установщик запрашивает только Simylator/main, отклоняет общие release contracts и чужие пути.
- Fresh install, обновление, rollback между PAPER-only релизами, блокировки активного сервиса и отсутствие автоматического старта.
- Переход существующего независимого PAPER сохраняет конфигурацию/пароль, SQLite identity/history и PAPER HTTPS; перед переключением делает SQLite backup.
- Архивный общий релиз остаётся на диске, но автоматический rollback на него блокируется.
- PAPER HTTPS использует подставной Windows adapter, подтверждения и существующие защиты, включая TLS и идентичность своего сервиса.

## Ещё не проверено

- Реальная установка Windows, venv/MetaTrader5, Tk/UAC и PowerShell.
- Подключение к настоящему MT5 и одновременная работа отдельного торгового приложения.
- Реальная выдача/продление сертификата, внешний маршрут с телефона, firewall провайдера.
- Визуальная геометрия в мобильном браузере.
- GitHub Actions на опубликованном commit. Workflow подготовлен, но не запускался на GitHub.

Эти ограничения не заменяются локальными mock-тестами. Никакое реальное торговое исполнение для проверки Simylator не требуется.

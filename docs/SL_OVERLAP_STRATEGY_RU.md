# Перекрытие на первоначальном SL (только PAPER)

Начальный STOP следует закрытым свечам, отступ по умолчанию 0.80, одна позиция 0.02, SL 1.00, TP 0.25. После подтверждения исполнения автоматически ставится противоположная лестница по 0.01 на первоначальный SL. После её исполнения ставится следующая встречная лестница.

SL переносится при ходе +0.25 на 0.25 ниже входа BUY (выше для SELL), при +0.40 на вход. Встречные STOP остаются на первоначальном уровне. После полного закрытия корзины по SL поддержки встречная лестница остаётся на первоначальной цене, а в прежнюю сторону добавляется STOP от номинального SL поддержки ±настроенный отступ входа (по умолчанию 0.80). Проскальзывание закрытия не сдвигает этот якорь. После исполнения одной стороны вторая отменяется (OCO), и только после подтверждённой отмены выставляется новая встречная лестница на первоначальном SL новой корзины. Полный исходный SL не добавляет лишнюю лестницу в прежнюю сторону. Ручное ухудшение SL также не считается SL поддержки.

## Выбор профиля

Прогноз RECOVERY для следующей лестницы включает текущий подтверждённый результат и ожидаемый результат закрытия оставшихся позиций по их текущему SL, включая известную комиссию закрытия. Прогноз не записывается в фактический журнал. Объём открытой корзины фиксируется до полного закрытия. Ещё не исполненная лестница пересчитывается при изменении SL, частичных TP и настроек диапазонов: прежние ордера отменяются, отмена подтверждается, затем ставится новый профиль на прежней цене входа. Если исполнение произошло во время отмены, уже исполненная корзина не увеличивается и не уменьшается; фактический RECOVERY учитывается в последнем TP.

| RECOVERY | Лот |
|---|---|
| <3.5 | 0.03 |
| 3.5–<6.5 | 0.04 |
| 6.5–<10 | 0.05 |
| 10–<15 | 0.06 |
| 15–<21 | 0.07 |
| 21–<28 | 0.08 |
| 28–<36 | 0.09 |
| 36–50 включительно | 0.10 |
| >50 | ручное продолжение |

Границы и соответствующие профили можно изменить в панели в ходе цикла без перезапуска, с пересчётом ожидающих лестниц, но без изменения объёма уже открытых позиций. Последняя верхняя граница включается; остальные не включаются.

TP по умолчанию:
- 0.03: 0.30 / 0.70 / 1
- 0.04: 0.50 / 1 / 1.50 / 2
- 0.05: 0.70 / 1.30 / 1.90 / 2.40 / 2.70
- 0.06: 0.70 / 1.30 / 2 / 2.80 / 3.30 / 3.90
- 0.07: 0.70 / 1.30 / 2.30 / 3 / 3.50 / 4.30 / 4.90
- 0.08: 0.70 / 1.30 / 2 / 3 / 3.70 / 4.70 / 5.70 / 5.90
- 0.09: 0.70 / 1.30 / 1.70 / 3.30 / 4 / 5 / 5.70 / 6.30 / 7
- 0.10: 0.70 / 1.30 / 1.70 / 3.30 / 4 / 5 / 5.70 / 6.30 / 7 / 9

Последний доступный TP корректируется под текущий RECOVERY за вычетом ожидаемой прибыли остальных открытых ступеней и с учётом известных издержек. Он может оказаться ближе предыдущей ступени. Неположительный остаток не превращает TP в убыточное закрытие. Ручная правка TP имеет приоритет.

Если промежуток котировок успел закрыть новую корзину до постановки следующего STOP, рыночная замена не выдумывается: требуется ручное продолжение. Если подтверждённая прибыль частичных TP уже покрыла RECOVERY, встречные ордера отменяются, затем остаток RECOVERY-корзины закрывается по текущей виртуальной цене. Окончательный результат учитывается без списания остаточного убытка. Начальная позиция с нулевым RECOVERY так не закрывается. При завершении цикла встречные ордера отменяются до записи завершения. Вся торговля виртуальная, реальных приказов в MT5 нет. Результат модели не обещает покрытие убытка на реальном рынке.

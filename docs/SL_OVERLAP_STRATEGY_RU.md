# Перекрытие на первоначальном SL (только PAPER)

Начальный STOP следует закрытым свечам, отступ по умолчанию 0.80, одна позиция 0.02, SL 1.00, TP 0.25. После подтверждения исполнения автоматически ставится противоположная лестница по 0.01 на первоначальный SL. После её исполнения ставится следующая встречная лестница.

SL переносится при ходе +0.25 на 0.25 ниже входа BUY (выше для SELL), при +0.40 на вход. Встречные STOP остаются на первоначальном уровне. После полного закрытия корзины по SL поддержки встречная лестница остаётся на первоначальной цене, а в прежнюю сторону добавляется STOP от номинального SL поддержки ±настроенный отступ входа (по умолчанию 0.80). Проскальзывание закрытия не сдвигает этот якорь. После исполнения одной стороны вторая отменяется (OCO), и только после подтверждённой отмены выставляется новая встречная лестница на первоначальном SL новой корзины. Полный исходный SL не добавляет лишнюю лестницу в прежнюю сторону. Ручное ухудшение SL также не считается SL поддержки.

## Выбор профиля

Прогноз RECOVERY для следующей лестницы включает текущий подтверждённый результат и ожидаемый результат закрытия оставшихся позиций по их текущему SL, включая известную комиссию закрытия. Прогноз не записывается в фактический журнал. Объём открытой корзины фиксируется до полного закрытия. Ещё не исполненная лестница пересчитывается при изменении SL, частичных TP и настроек диапазонов: прежние ордера отменяются, отмена подтверждается, затем ставится новый профиль на прежней цене входа. Если исполнение произошло во время отмены, уже исполненная корзина не увеличивается и не уменьшается; фактический RECOVERY учитывается в последнем TP.

| RECOVERY | Лот |
|---|---|
| <3.5 | 0.03 |
| 3.5–<6.5 | 0.04 |
| 6.5–<10 | 0.05 |
| 10–<15 | 0.06 |
| 15–<21 | 0.07 |
| 21–<28 | 0.08 |
| 28–<36 | 0.09 |
| 36–50 включительно | 0.10 |
| >50 | ручное продолжение |

Границы и соответствующие профили можно изменить в панели в ходе цикла без перезапуска, с пересчётом ожидающих лестниц, но без изменения объёма уже открытых позиций. Последняя верхняя граница включается; остальные не включаются.

TP по умолчанию:
- 0.03: 0.30 / 0.70 / 1
- 0.04: 0.50 / 1 / 1.50 / 2
- 0.05: 0.70 / 1.30 / 1.90 / 2.40 / 2.70
- 0.06: 0.70 / 1.30 / 2 / 2.80 / 3.30 / 3.90
- 0.07: 0.70 / 1.30 / 2.30 / 3 / 3.50 / 4.30 / 4.90
- 0.08: 0.70 / 1.30 / 2 / 3 / 3.70 / 4.70 / 5.70 / 5.90
- 0.09: 0.70 / 1.30 / 1.70 / 3.30 / 4 / 5 / 5.70 / 6.30 / 7
- 0.10: 0.70 / 1.30 / 1.70 / 3.30 / 4 / 5 / 5.70 / 6.30 / 7 / 9

Последний доступный TP корректируется под текущий RECOVERY за вычетом ожидаемой прибыли остальных открытых ступеней и с учётом известных издержек. Он может оказаться ближе предыдущей ступени. Неположительный остаток не превращает TP в убыточное закрытие. Ручная правка TP имеет приоритет.

Если промежуток котировок успел закрыть новую корзину до постановки следующего STOP, рыночная замена не выдумывается: при отсутствии ранее созданной встречной лестницы применяется описанное ниже следование за следующей закрытой свечой в пределах настроенного порога. Если подтверждённая прибыль частичных TP уже покрыла RECOVERY, встречные ордера отменяются, затем остаток RECOVERY-корзины закрывается по текущей виртуальной цене. Окончательный результат учитывается без списания остаточного убытка. Начальная позиция с нулевым RECOVERY так не закрывается. При завершении цикла встречные ордера отменяются до записи завершения. Вся торговля виртуальная, реальных приказов в MT5 нет. Результат модели не обещает покрытие убытка на реальном рынке.

## Обнуление отображаемого общего результата

Кнопка «Обнулить…» рядом с общим результатом после подтверждения сохраняет
новую точку отсчёта счётчика. Она не удаляет историю, не списывает RECOVERY,
не меняет открытые позиции, ордера, комиссии или настройки стратегии.
После перезапуска точка отсчёта сохраняется. Повторная доставка той же команды
не обнуляет счётчик повторно. При неполной истории сброс недоступен.

Счётчик, как и раньше, учитывает полный чистый результат только полностью
закрытых позиций. Если позиция открыта на момент сброса, её полный результат
с расходами открытия и закрытия попадёт в счётчик после окончательного закрытия.
Сама история продолжает показывать исходные результаты всех позиций.

## Мгновенное исполнение и закрытие без встречной лестницы

Если вся корзина успела открыться и закрыться между наблюдениями контроллера,
а её встречная лестница ещё ни разу не была создана, оставшийся RECOVERY не
переводит симулятор в ручное ожидание сам по себе. При долге в заданных пределах
выбирается профиль по фактическому результату и начинается следование со
следующей закрытой свечи, на расстоянии из настроек. Триггер не подменяется
рыночным ордером и не считается исполненным задним числом.

Первоначальные TP сохраняются: это изменение продолжения цикла, не модели
исполнения. Выше верхнего порога остаётся ручной режим. Явные остановки и
отмены встречной лестницы сохраняются; отмена ожидающей свечной лестницы
останавливает это следование. Повторный запуск сервиса не дублирует лестницы.

## Сброс цикла и RECOVERY с автоматическим новым циклом

Отдельная кнопка PAPER SL OVERLAP выполняет сброс одним нажатием. Она не ждёт
старые команды, правки, ручную сверку или обновление котировки. Ожидающие
виртуальные ордера отменяются, открытые виртуальные позиции закрываются по
последним допустимым наблюдаемым Bid/Ask. Цена и её время записываются в историю
сброса; её давность не выдаётся за свежую котировку. Фактический виртуальный P/L
и вся история остаются. Остаточный RECOVERY списывается отдельной записью, не
фиктивной прибылью и не удалением убыточных сделок.

Новый цикл включён сразу после атомарного сохранения: он автоматически начинает
следовать со следующей закрытой свечи, без дополнительной кнопки «Старт».
Невыполненные старые команды и старые наблюдения в очереди не могут оживить
прежний цикл. Повторная доставка того же нажатия не сбрасывает новый цикл ещё раз.
Сброс не обнуляет отдельный отображаемый общий P/L-счётчик.

Если позиций нет, отсутствие котировки не мешает сбросу. Если позиции есть,
но ни одной допустимой цены не сохранено, закрыть их без выдуманного результата
нельзя: будет явная ошибка без удаления позиций. Ошибки целостности истории и
записи SQLite также не скрываются. Реальный отказ источника котировок не создаёт
новые цены: результат сброса сохраняется, а отказ источника остаётся видимым.
LIVE-контур этой кнопки не имеет.
